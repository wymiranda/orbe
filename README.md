# Orbe

Um espaço pessoal para leituras e flashcards.

## Desenvolvimento

```bash
npm install
npm run dev
```

O app abre localmente no endereço mostrado pelo Vite. A rota `GET /api/health` responde pelo Worker.

## Comandos

```bash
npm run build
npm run lint
npm run deploy
```

O primeiro passo deliberadamente não usa banco nem armazenamento. Quando a primeira tela de leitura estiver definida, adicionaremos D1 para os textos e R2 para arquivos enviados.
