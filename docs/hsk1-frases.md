# Frases HSK 1

Rascunho de frases naturais para estudo. Todas têm até 12 hanzi, sem contar a pontuação. A dificuldade aumenta pela estrutura gramatical, não apenas pelo tamanho.

## Critério

Frases de conversa real e reutilizáveis: apresentação, rotina, tempo, compra, deslocamento, convite, opinião e pergunta. Evitar combinações artificiais feitas apenas para encaixar vocabulário.
