# Frases HSK 2

Frases naturais para estudo cumulativo: HSK 1 + HSK 2. A cobertura mede os verbetes novos do HSK 2; o HSK 1 é base permitida. Todas têm no máximo 12 hanzi, sem contar a pontuação.
